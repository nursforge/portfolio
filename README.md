# Портфолио Нурсултана Манапова

Папка готова к публикации через GitHub Pages.

## Публикация

1. Создай GitHub-репозиторий для сайта.
2. Загрузи **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, `app.js`, `favicon.svg` и папку `projects`.
3. В настройках репозитория открой **Settings → Pages** и выбери публикацию из ветки `main`, папка `/ (root)`.
4. GitHub покажет адрес опубликованного сайта в том же разделе Pages.

Внутри `projects` лежат локальные копии пяти демо-сайтов и их изображений. Исходные проекты в соседних папках `outputs` не менялись.

## Особенность Cover Lab

Редактор обложек и его canvas-превью работают как статическая страница. Генерация фона через ИИ обращается к Node.js API из `server.mjs`; GitHub Pages не запускает Node.js сервер. Для этой функции потребуется отдельно разместить API на серверной платформе и настроить `OPENAI_API_KEY` в окружении сервера. Сам ключ нельзя помещать в браузерный код.
