# Cover Lab

Студия музыкальных обложек: векторные композиции создаются в браузере, а фон по текстовому описанию генерирует OpenAI Images API. Текст артиста и релиза накладывается отдельно на Canvas — он остаётся чётким и редактируемым.

## Запуск

Нужен Node.js 20 или новее.

1. Создай API-ключ в [OpenAI API Platform](https://platform.openai.com/api-keys).
2. В этой папке скопируй `.env.example` в `.env`.
3. Открой `.env` и замени `your_api_key_here` на свой ключ.
4. В терминале, открытом в папке `cover-lab`, запусти `npm start`.
5. Открой адрес, который появится в терминале — по умолчанию `http://127.0.0.1:3000`.

Файл `.env` находится в `.gitignore`: ключ не попадёт в браузерный код и случайно не сохранится в Git. Не отправляй API-ключ в чат и не публикуй его.

## Как работает генерация

Браузер отправляет серверу описание идеи, выбранный стиль и палитру. Сервер формирует промпт, запрашивает квадратный фон через Images API, затем возвращает изображение браузеру. Canvas накладывает имя артиста и релиза поверх фона; итоговая обложка скачивается в PNG.

Кнопка «Новый вариант без ИИ» оставляет доступной процедурную генерацию, которая работает без API-ключа и сетевого запроса.

## Важно

Для API требуется отдельная настройка оплаты; подписка ChatGPT не включает расходы на API. Доступность модели может зависеть от верификации организации и настроек API-аккаунта. Перед открытием сайта в публичный интернет добавь пользовательскую аутентификацию, лимиты генерации и защиту от автоматических запросов.
